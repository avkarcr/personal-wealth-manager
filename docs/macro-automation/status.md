## Последняя подтверждённая проверка

- М10: **385 Python-тестов**, **17 JavaScript-тестов**, Chromium-сценарии М8/М9/М10 на синтетических vault — успешно. Покрытие кода М10 с ветвлениями — 99%.
- [GitHub Actions run 45842237134](https://github.com/avkarcr/personal-wealth-manager/actions/runs/45842237134) для точного SHA `4539bb6…`: `tests (3.9)`, `tests (3.12)` и `macro-browser` завершены успешно. Порог пакета без legacy routes — 95%.
- Это результат проверки реализации, не полный аудит полезности тестов, не аудит безопасности и не историческая калибровка. Личные данные пользователя не использовались.
- При передаче сверены локальные SHA всех 321 отслеживаемого файла с удалённым деревом М10: исходных пользовательских расхождений не было. Подготовлены только Markdown-документы; код, тесты, зависимости и схема не изменяются этой задачей.
- Ревизия передачи: проверены 177 относительных ссылок/якорей в изменённых документах и 25 описанных HTTP-маршрутов по коду; все девять вопросов готовности новой сессии имеют указанный источник. Секреты и приватные данные в изменениях не обнаружены. Существующее ТЗ и полезные исторические документы сохранены; устаревший архитектурный текст явно помечен историческим. Повторный локальный прогон функциональных тестов для этой правки документации не выполнялся; результат выше относится к точному SHA М10.

## Незавершённое и ограничения

| Пункт | Состояние / действие |
|---|---|
| М11 | Поиск/фильтры/переход отрасль → компании на существующем каталоге. Прежде оценить доступность конкретных company-метрик и официальный ISS-контракт; не переносить отраслевой балл на компанию и не создавать фиктивные переходы |
| М12 | Реальные исторические срезы, look-ahead, пересмотры, чувствительность, производительность, E2E и итоговые ограничения; не выполнен |
| Остаток М4 | Автоматический Росстат не реализован. Проверки 17/21.11 получили HTTP 503, ЕМИСС 17.11 — 403. Это исторические результаты, не новая проверка доступности 26.11. Импорт CSV/XLSX работает |
| Решение по поставщику | 22.11 пользователь отложил замену Росстата до опыта эксплуатации. Не выбирать альтернативу автоматически |
| М10 данные | Фундаментальные/рыночные отраслевые агрегаты вводятся вручную с методикой, датами и охватом. Автопоставщика fundamentals нет |
| История | Неизвестные даты публикации видны в `known` только с получения; старые винтажи нельзя восстановить догадкой. Текущая классификация компаний не является историей принадлежности |
| Модели | Численные веса/профили — гипотезы. Уверенность не вероятность; рейтинги не гарантируют доходность. М12 остаётся необходимым |
| Технический долг | Полная копия/шифрование vault, растущие неизменяемые снимки и полное чтение части истории; измерения на реалистичном объёме в М12. Синхронный ручной refresh, общий backoff без Retry-After, окно пересмотров 7 дней — [М5](M5-market-refresh.md) |
| Совместимость | Legacy routes/calc, старые поля компаний и read-only views сохранены намеренно; не удалять в рамках М11 без зависимости от задачи |
| Прочие подсистемы | Нативные выписки требуют образцов; шорты/FX-конвертация/корпоративные действия и другие текущие ограничения — [project-history.md](../project-history.md) |

Подтверждённого падения текущего набора тестов или отдельного блокера начала М11 не выявлено. Неподключённые поставщики блокируют соответствующие автоматические данные, а не работу всей программы. Полный список ошибок эксплуатации по личному vault недоступен; отсутствие CI-ошибок не означает отсутствия дефектов.

## Как продолжить

1. Сверить текущую удалённую ветку и локальные правки. Не использовать `main` как вершину М10.
2. Прочитать [план М11](plan.md#м11-company-explorer), [каталог М9](M9-catalog.md), [границы М10](M10-sector-scoring.md) и раздел 7 [исходного ТЗ](../specs/macroeconomic-dashboard-automation.md).
3. При команде на М11 начать с `modules/market_catalog`, `companies`, `instruments`, существующих карточек и web-адаптеров. Сначала определить подтверждённые поля/источники, затем реализовать только М11.
4. Сохранить результат, проверки, ограничения и новый проверенный SHA в этом файле; обновить план/документ этапа и остановиться. М12 и полный аудит не запускать автоматически.

Для остановленной работы записывать здесь незакоммиченные файлы, что именно осталось и какие проверки уже выполнены. На функциональной базе М10 незавершённого кода не осталось. Пробелы восстановленной истории перечислены в [project-history.md](../project-history.md#границы-восстановления-контекста).
