# Капитал — локальный учёт инвестиций

Минималистичное веб-приложение для учёта брокерских счетов, криптобирж и кошельков, недвижимости
и доходов — включая фриланс.
Работает только на вашем компьютере. Данные хранятся в одном **зашифрованном** файле `invest.enc`.

## Запуск
Нужен Python 3.9+ (python.org).

- **Windows:** двойной клик по `run.bat`
- **macOS:** двойной клик по `run.command` (при первом запуске: правый клик → Открыть)
- **Linux:** `./run.sh`

Первый запуск сам создаст окружение и поставит зависимости (Flask, cryptography).
При первом открытии приложение попросит придумать пароль. Браузер откроется на http://127.0.0.1:5050.
Вручную: `pip install -r requirements.txt && python app.py`.

## Как вести учёт
1. **Счёт** — брокерский счёт/ИИС, криптобиржа или кошелёк, объект недвижимости, «прочее» (металлы, вклад),
   либо **фриланс** — площадка или постоянный клиент. Фриланс не входит в капитал, только в доходы.
2. **Позиции** (для брокера и прочего) — тикер, количество, средняя и текущая цена.
   Свободные деньги на счёте — позицией класса «Деньги». Цены обновляются кнопкой «Обновить цены»
   (все сразу), «Цены с MOEX» (по тикерам Мосбиржи) или «Цены с бирж» для крипты
   (BTC, ETH… — цена в USDT с Binance, Bybit или OKX; цену монет удобно вести в USD).
3. **Операции:**
   - *Пополнение / Вывод* — ваши деньги, внесённые или забранные. На них строится «Вложено» и годовая доходность (XIRR).
   - *Доход* — дивиденды, купоны, аренда, стейкинг, фарминг, аирдропы, P2P, оплата за проект.
     У дохода есть **категория** (подсказки зависят от типа счёта) и **источник** — бумага, монета/протокол или клиент.
   - *Расход* — комиссии, налоги, газ, содержание.
   - Доход можно записать прямо в монетах (0,012 ETH) — добавьте курс монеты в «Курсах и данных»
     (вручную или кнопкой «Курсы крипты»).
   - Неоплаченный фриланс-заказ отмечайте «ожидается»: он не попадёт в доходы, пока не нажмёте «Получено».
   - Для недвижимости доход и расходы входят в прибыль. Для брокера и крипты — только статистика
     (деньги и монеты уже учтены в позициях).
   - Покупка недвижимости автоматически записывается пополнением при создании объекта.
4. **История** — снимок стоимости сохраняется автоматически при каждом открытии/изменении.
   Прошлые значения можно внести кнопкой «+ Прошлая оценка» на странице счёта.

Если пополнений нет, «Вложено» считается по средней цене покупки позиций.

## Доходы
Раздел «Доходы» собирает всё вместе: пассивный доход и фриланс по месяцам, разбивку по категориям
и источникам, среднее в месяц и список ожидаемых оплат. На странице фриланс-площадки — оплаты по клиентам
и оценка налога по ставке (например, НПД 4 % или 6 %).

## Обновление со старой версии
Замените файлы приложения, а `invest.db` оставьте рядом. При первом запуске приложение попросит придумать пароль,
перенесёт данные в зашифрованный `invest.enc`, а открытый `invest.db` перезапишет и удалит.
(На SSD перезапись не гарантирует физическое удаление — при желании удалите и старые копии этого файла.)

## Шифрование
- База шифруется AES-256-GCM; ключ получается из пароля через scrypt. Пароль нигде не сохраняется.
- Расшифрованные данные существуют только в памяти, пока приложение разблокировано. На диск пишется только зашифрованный файл
  (после каждого изменения), плюс предыдущая версия `invest.enc.bak` — тоже зашифрованная.
- Кнопка «Заблокировать» в меню и автоблокировка после 15 минут бездействия (настраивается).
- Смена пароля — в «Курсах и данных»; файл при этом перешифровывается.
- **Если забыть пароль, данные восстановить невозможно.** Храните пароль в менеджере паролей, а копию `invest.enc` — где угодно.
- Экспорт в CSV — единственное, что выгружается открытым текстом (приложение предупредит).

## Аренда недвижимости
- **Договор**: арендатор и контакт, срок (окончание можно не указывать), ставка в любой валюте, периодичность
  (месяц, квартал, полгода, год, посуточно), число оплаты, залог, риелтор/управляющий и его вознаграждение,
  кто платит коммуналку, прочие условия.
- **График платежей** создаётся автоматически по периодичности; просроченные подсвечиваются.
- **Статусы платежа**: «Ожидается» → «Отдал риелтору» (деньги у риелтора — видно сумму долга) → «Деньги у меня».
  При получении вводите, сколько вы получили и в какой валюте — курс посчитается сам. Курс ЦБ на дату для сравнения
  подтягивается кнопкой; видно, сколько потеряли на конвертации.
- **Простой** считается по датам договоров: заполняемость за год, дни простоя и полоса занятости.
- Полученные платежи автоматически попадают в операции и доходы (в той валюте, в которой пришли).

## Данные и приватность
- Сеть используется только по кнопкам «Курсы ЦБ» (cbr.ru), «Цены с MOEX» (iss.moex.com), «Цены с бирж»
  и «Курсы крипты» (публичные API Binance / Bybit / OKX). Передаются лишь тикеры, без ключей и личных данных.
- Сервер слушает только 127.0.0.1 — из сети он недоступен.
- Порт можно сменить: `PORT=8000 python app.py`.

## Архитектура и разработка

Начат поэтапный переход на hexagonal-архитектуру: сохранение счёта и смена языка
вынесены в независимые сценарии с портами, SQLite-адаптерами и UnitOfWork.
В **Настройки → Общие** можно выбрать русский или английский язык интерфейса.
Выбор сохраняется в зашифрованном хранилище.

Подробности, ограничения переходного этапа и целевая структура меню:
[docs/architecture.md](docs/architecture.md).

```bash
python -m pip install -r requirements-dev.txt
python -m coverage run -m unittest discover -s tests -v
python -m coverage report
python -m coverage report --include='wealth_manager/*' --omit='wealth_manager/adapters/web/legacy_routes.py' --fail-under=95
```

### Фабрика приложения и жизненный цикл

`python app.py` и существующие скрипты запуска работают как прежде. При импорте
`app` приложение, хранилище и потоки не создаются. `create_app()` создаёт независимый
экземпляр Flask; конфигурация читается при вызове фабрики.

```python
from app import create_app

app = create_app({"VAULT_PATH": "/path/to/invest.enc", "IDLE_MINUTES": 15})
runtime = app.extensions["wealth_manager"]
try:
    runtime.start()  # фоновая автоблокировка; повторный вызов безопасен
    app.run(host="127.0.0.1", port=5050, use_reloader=False)
finally:
    runtime.close()  # останавливает поток, сохраняет и блокирует хранилище
```

В тестах фон не запускается: достаточно создать приложение и затем закрыть runtime.
Проверка бездействия при защищённом HTTP-запросе работает и без фонового потока.
`runtime.close()` вызывается владельцем приложения вне запроса, а не из Flask teardown.
Каждому независимому экземпляру нужен собственный файл хранилища.

Порог 95% применяется к новому коду. `legacy_routes.py` содержит перенесённые старые
обработчики: они входят в общий отчёт покрытия, но не в порог нового пакета.

### Цели и портфели

В «Настройки → Цели» создайте финансовую цель с суммой и валютой. В разделе
«Портфели» создайте портфель и выберите для него одну цель. Несколько портфелей
могут работать на одну цель. Добавляйте доли позиций со счетов и недвижимости
(0,01–100%): сумма долей одного актива во всех портфелях не может превышать 100%.

Прогресс цели рассчитывается по текущим оценкам и курсам. Доли следуют за
изменением количества и стоимости активов; общий капитал на дашборде не
увеличивается от распределения. При отсутствии курса прогресс не рассчитывается.
Цели, портфели и доли сохраняются в том же зашифрованном хранилище; при первом
открытии выполняется автоматическая миграция схемы до версии 7.

### Компании, макроэкономика и налоги

- **Компании:** список наблюдения с тикером, биржей, страной, сектором, сайтом
  и инвестиционной идеей. Статусы меняются вручную.
- **Макроэкономика:** история ставок, ИПЦ, ВВП и доходностей гособлигаций
  по странам. Добавляйте дату, значение и источник; приложение показывает
  последнее значение и изменение относительно предыдущего наблюдения.
- **Налоги:** база, введённая ставка, оценка налога и уплата, отдельно по году,
  стране и валюте. Для вычетов — расходы, ожидаемый/полученный возврат, статус
  и реквизиты документов. Загрузка файлов документов пока не предусмотрена.

Эти разделы работают с ручным вводом, поддерживают RU/EN и сохраняются в
зашифрованном хранилище. Нормативные ставки автоматически не подставляются;
вычеты не уменьшают налог автоматически и не создают денежные операции.

### Категории и язык интерфейса

Встроенные классы активов и категории операций хранятся стабильными кодами,
а отображаются на выбранном языке RU/EN. Для собственного названия выберите
«Своя категория»: оно сохраняется без перевода. При обновлении старые
встроенные значения автоматически мигрируют; остальные категории, названия
и заметки сохраняются. Суммы и распределения портфелей не меняются.

Все семь этапов первоначального плана архитектурного рефакторинга завершены.
