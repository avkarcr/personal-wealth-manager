# М3 — загрузка ключевой ставки и кривой ОФЗ из ЦБ

Ветка: `feature/macro-dashboard-automation`. М4 начинается только после отдельной команды.

## Результат

На странице «Макроэкономика» появилась форма «Загрузить данные ЦБ»: выбор ключевой ставки либо кривой ОФЗ, начало/конец периода, состояние загрузки и сообщения RU/EN. Результат открывается на странице «Ряды и версии данных». Существующая ручная сводка остаётся ручной; объединение источников и аналитический дашборд относятся к М7–М8.

Адаптер использует проверенные HTML-таблицы:

- https://www.cbr.ru/hd_base/KeyRate/ — дата значения и ключевая ставка в процентах годовых.
- https://www.cbr.ru/hd_base/zcyc_params/ — дата кривой и сроки до погашения. Загружаются 1, 2, 5 и 10 лет по заголовкам столбцов, а не по неподтверждённым позициям.

Параметры `UniDbQuery.Posted`, `UniDbQuery.From`, `UniDbQuery.To` подтверждены формой сайта и прямыми GET-запросами. Ответ обязан содержать подтверждение запрошенного диапазона. SOAP и новый REST API не используются: табличный канал проверен, лишних резервных каналов с неподтверждённым контрактом нет.

## Семантика

- Ряд ставки — ежедневные значения из таблицы. Дата значения **не является датой решения или публикации**. Пресс-релизы решений не разбираются. Выходные/пропуски не достраиваются.
- Кривая имеет отдельные коды `ofz_zero_1y`, `ofz_zero_2y`, `ofz_zero_5y`, `ofz_zero_10y`. Старые ручные `yield_2y/yield_10y` не переименовываются и не затираются.
- Все значения — Decimal, единица `percent`, частота `daily`. Нет интерполяции, усреднения и расчёта спредов (М6).
- Для исторических строк таблицы нет подтверждённого времени публикации конкретной версии: `published_at` остаётся неизвестным. Строгий as-of начинает видеть эти данные с получения. Для просмотра загруженных старых периодов доступен явно обозначенный режим последних версий.
- Полный ответ, адрес запроса, SHA-256 и версия парсера `cbr-html-v1` сохраняются внутри зашифрованного vault. Ревизия ссылается на исходный ответ, которым впервые подтверждено её значение. Новая HTML-оболочка или пересечение диапазонов сами по себе не создают ревизий; изменившееся значение создаёт версию. Повтор уже известного исходного пакета не возвращает старую версию поверх новой. Возврат к прежнему значению с новым исходным ответом сохраняется как новая версия.

## Ограничения и отказоустойчивость

Одна операция — один выбранный источник и не более 366 календарных дней. Начало ставки — не ранее 17.09.2013, кривой — не ранее 04.01.2003; будущие даты запрещены. Это границы доступности источника, а не обещание полноты всех строк.

GET только по фиксированным HTTPS-адресам, редиректы запрещены, socket timeout 15 секунд, тело до 2 МБ. Неожиданная разметка, неверные числа/даты/диапазон/дубликаты приводят к ошибке без частичной записи. Пустые ячейки и тире — отсутствие значения, не ноль. Пустой период сообщает об отсутствии наблюдений. Сохранение четырёх сроков кривой атомарно.

Сеть работает вне блокировки vault и вне транзакции. До запроса и перед записью проверяется поколение разблокированного хранилища. Lock/unlock во время запроса отменяет запись, HTTP возвращает пользователя к разблокировке. Автоматическое обновление, расписание, retry/backoff и журнал запусков — М5.

## Проверки

Контрактные фикстуры `tests/fixtures/cbr/*.html` — реальные ответы ЦБ на диапазон 01–20.11.2026, полученные 21.11.2026. Оба запроса HTTP 200: ставка — 14 строк, кривая — 14 дат × 4 выбранных срока. Фикстуры содержат исходную HTML-страницу, а не выдуманный API. Обычный CI не обращается в сеть. Дополнительно прямым вызовом рабочего адаптера проверен диапазон 09–12.01.2024: по четыре даты в ставке и каждом из четырёх сроков ОФЗ.

13 новых тестов: контракт/точные значения, неизвестные публикации, ошибки формата и диапазона, пропуски, лимиты/таймауты, идемпотентность, ревизии, ручные данные, атомарность, lock/unlock, отсутствие блокировки во время HTTP, RU/EN. Полный набор — 259 Python-тестов; frontend — 9 тестов. Порог покрытия прикладного пакета остаётся 95%.

Условия и атрибуция: https://www.cbr.ru/user_agreement/ и https://www.cbr.ru/About/?PrtId=use . Интерфейс содержит ссылки на источники. Отдельные условия MOEX/рыночных API проверяются в М5; использование таблицы ЦБ не объявляется универсальным разрешением на распространение биржевых данных.
