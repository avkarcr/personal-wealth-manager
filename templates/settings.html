Приватность

Приложение работает только на вашем компьютере (127.0.0.1) и ничего не отправляет. Данные зашифрованы паролем, который нигде не хранится. Внешние запросы происходят только по кнопкам: «Курсы ЦБ» (cbr.ru), «Цены с MOEX» (iss.moex.com), «Цены с бирж» и «Курсы крипты» (публичные API Binance, Bybit, OKX). Передаются только тикеры — без ключей и личных данных.
